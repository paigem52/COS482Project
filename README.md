# COS482Project
This data science project focuses on the impacts of AI in an environmental sector

Useful Info:
Clone Repository:
git clone git@github.com:paigem52/COS482Project.git

Navigate into the cloned repository
cd COS482Project

Make and commit changes:
git add .
git commit -m "Descriptive commit message for changes"

Main branch:
Only for finished, good work.

Personal branch:
Copy of main project files to edit. 

Switch to existing branch:
Older version: git checkout branch-name
Newer version: git switch branch-name



Changes from local branch to remote repository
git push origin branch-name

Approve changes of branch to main:
Git website --> pull requests, green merge button

Changes from remote repository to local branch (takin current up-to-date main)
git checkout main
git pull origin main

Good to check and make sure they are both up-to-date on terminal
