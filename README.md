Older version: git checkout branch-name  <br>
Newer version: git switch branch-name  <br><br>

<h3>Changes from local branch to remote repository</h3>
git push origin branch-name  <br><br>

<h3>Approve changes of branch to main:</h3>  
Git website --> pull requests, green merge button <br><br>

git pull origin main <br> <br>
